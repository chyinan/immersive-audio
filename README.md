# Immersive Audio Page

一个展示沉浸式音频制作服务的个人作品集网页。

## 项目简介

这是一个使用 HTML、CSS 和 JavaScript 构建的单页面应用，展示了 Dolby Atmos 音频混音服务。页面采用现代化的设计风格，包含动画效果和响应式布局。

## 技术栈

- HTML5
- Tailwind CSS (CDN)
- 原生 JavaScript
- Google Fonts (Inter)

## 功能特性

- 响应式设计，支持移动端和桌面端
- 平滑滚动导航
- 动画效果和交互体验
- 玻璃态卡片设计
- 渐变色彩方案

## 使用方法

直接在浏览器中打开 `index.html` 文件即可查看页面。
